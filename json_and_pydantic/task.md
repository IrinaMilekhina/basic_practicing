## Немножко теории

Pydantic — это библиотека, которая встроена в FastAPI и используется для работы с данными. Она помогает проверять и преобразовывать данные, чтобы они соответствовали нужным форматам.

Pydantic заточен на то что бы проверять запросы, а самый распространенный формат для запросов - это json

Мы можем описать схему, которой должен соответствовать json, для этого создается класс и наследуется от BaseModel

Прочитать пример вот тут
https://docs.pydantic.dev/latest/concepts/models/#basic-model-usage

Один такой класс описывает только один уровень структуры json-файла:
```json
{
  "first_class": 1,
  "still_first_class": {
    "second_class": {
      "third_class": "aaa"
    }
  }
}
```

для того что бы прогнать такой объект через pydantic тебе понадобятся 3 класса
```python
from pydantic import BaseModel


class ThirdClass(BaseModel):
  third_class: str


class SecondClass(BaseModel):
  second_class: ThirdClass


class FirstClass(BaseModel):
  first_class: int
  still_first_class: SecondClass
```
